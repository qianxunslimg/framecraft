# Framecraft 网页音乐获取流程

本流程供 AI 为动画寻找、下载和接入背景音乐使用。适用于用户明确要求“从网上找音乐”的作品，也可作为已有素材不满足需求时的补充路径。第一版可直接利用 AI 客户端的搜索和浏览器能力执行，不要求先开发音乐网站 SDK。

## 接收音乐需求

从用户需求和作品 brief.md 提取风格、情绪、是否有人声、视频长度、旁白情况，以及已知的使用用途。把条件整理成一两句话即可，例如“30 秒中文科技介绍，无歌词、有节奏但不抢旁白，找可下载并适用于视频配乐的曲目”。

用户指定曲目或来源时保留该限制。未授权费用时，优先寻找免费且用途清晰的下载来源；普通搜索、试听和下载不增加额外确认步骤。

## 搜索与选择

先查看已有本地音乐是否已被指定或能够直接复用。需要网页获取时，搜索曲目并进入原始曲目页面，检查作者、实际下载入口和对应使用说明。

可以查看 Pixabay 等有音乐分类和下载入口的网站。Pixabay 的下载操作与可用文件以当前媒体页面为准，其许可也包含对原素材独立分发的限制。FMA 提供许可证说明，使用时需要阅读具体曲目的许可，不把网站名当作所有曲目都适用的许可。[Pixabay FAQ](https://pixabay.com/service/faq/) · [Pixabay 许可](https://pixabay.com/service/license-summary/) · [FMA 许可说明](https://freemusicarchive.org/License_Guide)

通常比较两到三首候选曲即可。根据实际试听、播放或音频分析判断节奏和是否适合旁白；未实际听到的曲目不能写成“试听通过”。用户没有要求逐曲挑选时，AI 可以直接选出最符合条件的曲目，并保留选择说明。

## 下载与保存

通过网站提供的可用下载链接或正常浏览器下载操作，取得文件并保存到 public/作品/external/audio。文件没有成功保存前不标记下载完成。

遇到页面需要当前缺少的登录状态或下载不可用时，记录具体情况并继续尝试其他符合需求的来源。只允许指定曲目或网站时，保留该限制并说明缺失条件。不要把试听地址、网页 HTML 或搜索结果当作音频文件。

保存文件后，用可用媒体工具确认它能解码，记录实际时长与必要音频信息，并计算 SHA-256。使用新的文件名保存替换曲目，避免破坏旧成片所引用的音乐。

## 记录来源

在 projects/作品/assets.json 记录素材 ID、类型、角色、本地相对路径、曲目页面、标题、作者、下载时间、文件指纹以及对应的使用说明。来源页面与许可证页面分开记录，需要署名时保留署名文本。

有下载证书或其他许可凭证时一并保存到本地并记录路径。保存包含使用说明的相关摘录或页面快照，以便后续核对。不要在公开记录中保存凭据或带访问密钥的下载地址。

仅知道来源页面但没有查清视频使用条件时，usage.status 保持 unverified。明确支持当前用途后更新状态和证据。能下载与能用于目标作品分别记录，不把未知条件自动写成已满足。

第三方音乐原文件默认不提交到公开 Git 仓库。作品源码和来源记录可以保存，是否允许分发音乐原文件另行依据对应条款判断；需要的署名可以写入交付说明。下载证书与本地文件也不因使用 Git LFS 而自动获得分发许可。

## 接入与成片检查

在作品源码中使用本地文件，选择合适片段，设置音量和淡入淡出。有旁白时检查音乐是否遮盖语言；需要循环或剪辑时同时核对相关使用条件。Remotion 可以直接引用 public 文件并使用 Audio 完成音频接入。[Remotion Audio](https://www.remotion.dev/docs/media/audio)

实际播放预览，再导出并播放完整成片。检查音乐确实是选择的曲目、开头和结尾合适、没有意外静音或音量突变，以及旁白清楚。只看到音轨存在不能代替完整试听。

交付时提供成片路径、曲目来源和必要署名。若最终没有成功取得或使用网页音乐，明确记录结果；合成音乐可以作为另一种来源，但不能把它描述为已完成网页下载。

## 第一版真实验收

真实例子为 `web-music-demo`：从 Kevin MacLeod 的原始网站选择 Pixelland，核实页面下载入口与 CC BY 4.0 署名，将 MP3 保存到本地并接入 12 秒作品。来源依据见 [music-source.md](../projects/web-music-demo/music-source.md)，媒体事实见作品 assets.json；视频与检查记录在对应 out 版本目录。

```sh
# 首次添加新素材；请求文件由 AI 根据核实后的页面整理
npm run asset:add -- <作品ID> <请求JSON>

# 已有登记但本地文件缺失时恢复；验证原指纹，不覆盖改变的文件
npm run assets:restore -- web-music-demo projects/web-music-demo/music-request.json
npm run assets:check -- web-music-demo
npm run render -- web-music-demo
```

当前脚本支持正常 HTTP(S) 链接和本地音视频文件，不承担网站登录或自动选曲。恢复模式可以在新 clone 中下载 Git 忽略的音乐；上游文件内容改变时会拒绝指纹不符的恢复，让新素材使用新 ID。
