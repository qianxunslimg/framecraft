# 技术核验与素材来源（autodrive-explained）

## 行业严谨技术核验清单（SAE J3016 & 2025–2026 行业共识）
- **SAE J3016 L0–L5**：L0 仅预警/瞬时介入（如 AEB）；L1 单维度辅助（纵向或横向）；L2 组合辅助（含绝大多数量产车的高速/城区 NOA，法定责任与监督义务仍在驾驶员）；L3 有条件自动驾驶（ODD 内系统负责，请求接管时人需及时接管）；L4 限定区域高度自动驾驶（无需人类接管，如 Robotaxi、港口/矿区、特定干线物流）；L5 全场景无限制完全无人驾驶。
- **三大传感器物理边界**：Camera（语义最强/成本低，但怕黑夜逆光雨雾且单目缺直接测距）；Radar（无线电波穿雨雾强、多普勒测速准，传统 3D 缺高度与角分辨率易滤静态目标，4D 毫米波正补强高度）；LiDAR（主动激光测厘米级 3D 点云、不怕黑夜，但成本相对高、无法直接认颜色文字、特大暴雨浓雾仍有噪点衰减）。
- **定位与无图化**：普通 GPS 误差 3–10m 且隧道丢星；组合定位融合 GNSS+RTK、IMU 惯性推算与传感器特征匹配达到厘米级。
- **四代技术演进客观特点与短板**：
  1. **高精地图 + 模块化规则**：白盒可解释、确定性高，但测绘贵、修路更新慢、难跨城、规则写不完。
  2. **BEV + 占用网络（Occupancy）无图化**：Transformer 跨视角融合实现在线建图“全国都能开”；Occupancy 三维体素网格无视白名单类别识别任意异形障碍物，代价是三维稠密计算量极大。
  3. **端到端大模型（End-to-End）**：打破模块壁垒信息无损、驾驶高度拟人；短板为黑盒难排查、长尾与安全难数学兜底，量产普遍外挂规则安全护栏兜底。
  4. **VLA（视觉-语言-动作模型）与世界模型（World Model）**：VLA 赋予常识/文字路牌/手势/语音指令逻辑推理能力（难点为推理延迟与幻觉，常靠快慢双系统/隐空间推理化解）；世界模型通过物理因果推演预演未来，算力消耗居金字塔尖，目前作为云端仿真/数据合成与强化学习基座并探索车端轻量化推演。
- **长尾与数据闭环**：最后 1% 极端 Corner Case 通过车端采集 + 云端世界模型虚拟仿真（日跑数百万公里）+ 训练与 OTA 升级构成数据飞轮。

## 音频与画面归属
- **配音**：Edge TTS `zh-CN-YunxiaNeural` 本地脚本生成并全篇逐段实听验收。
- **配乐与音效**：本地 Python 合成（`scripts/bgm.py`），118 BPM C 小调原创科幻电子发布会配乐。
- **视觉与动画**：全部由 HTML5 2D/3D 投影 Canvas、SVG 与 React/Remotion 代码原创实时渲染。
