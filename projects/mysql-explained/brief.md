## 8 大幕知识结构（严格对标现代 MySQL 8.0 + InnoDB）
1. **01 · 一条 SQL 的内部旅程**：Server 层（连接器/解析器/优化器/执行器，点明 8.0 已移除查询缓存）vs 插件式存储引擎层。
2. **02 · 存储引擎大对决**：InnoDB（事务、行锁、MVCC、崩溃安全恢复）vs MyISAM（无事务、表锁、无崩溃恢复）+ Memory 一句话定位。
3. **03 · B+Tree 索引完全通透**：16KB 磁盘页、3 层存 2000 万行、叶子双向链表（为什么不用 Hash）、聚簇索引 vs 二级索引、回表与覆盖索引、联合索引最左前缀与 3 大索引失效坑。
4. **04 · 事务与 ACID 底层靠山**：转账 500 元断电不丢钱，逐条拆解 A（Undo Log）、C（最终目标）、I（锁 + MVCC）、D（Redo Log）。
5. **05 · 并发三怪事、隔离级别与 MVCC 魔术**：脏读/不可重复读/幻读、四大隔离级别（InnoDB 默认可重复读）、Undo Log 版本链 + Read View 快照读如何实现读写无阻塞，一句话讲清读已提交与可重复读的 Read View 生成差异。
6. **06 · 锁机制全景与线上避坑**：表锁 vs 行锁、共享锁(S)/排他锁(X)、Record Lock / Gap Lock / Next-Key Lock、无索引更新退化锁整表惨案、死锁成因与固定顺序加锁解法。
7. **07 · Buffer Pool 与三大日志真相**：内存缓冲池 + WAL、彻底分清 Redo Log（持久性）、Undo Log（回滚 + MVCC）、Binlog（归档/主从复制/误删恢复）及两阶段提交（Prepare → Binlog → Commit）。
8. **08 · 一图收藏全景架构 + 避坑清单**：端到端知识蓝图 + 记忆口诀 + 准点下班彩带谢幕。
