# 手机 Root 底层解密（phone-root）

## 创作目标
- **题材**：硬核趣味科技科普——掀开智能手机的外壳，深入 Linux 内核、安全启动信任链、Magisk/KernelSU 架构与 TEE 硬件防线，讲透「什么是手机的 Root」。
- **画风**：暗黑赛博科技电影美学（Obsidian `#03060E` + Electric Cyan `#00F0FF` + Matrix Emerald `#00FF9D` + Crimson `#FF2A5F` + Vault Gold `#FFB800`），100% 全屏 1920×1080 实时 3D 硬件/内核/光路可视化，零 PPT 卡片、零项目符号。
- **节奏与时长**：约 3 分钟（7 大幕、20 个高密度视觉节拍），快节奏科技解说（+14% 语速）+ 128 BPM 暗黑赛博电子配乐 + 精准卡点 SFX。
- **画幅与帧率**：1920×1080 @ 30fps，立体声 48kHz 音频。
