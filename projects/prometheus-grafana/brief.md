# 一集彻底搞懂 Prometheus + Grafana（运维小牛马监控篇）

- **项目 ID**：`prometheus-grafana`
- **画幅 / 帧率**：`1920 × 1080`（16:9 横屏），`30 fps`
- **目标定位**：零基础也能彻底看懂、且经得起资深云原生工程师检验的监控可观测性科普动画。
- **主角阵容**：「运维小牛马」+「Prometheus 火焰管家」+「Grafana 彩虹大屏」
- **核心覆盖**：黑盒运维痛点 → 时序数据库 TSDB 与数据模型 → 4 大指标类型（Counter / Gauge / Histogram / Summary）→ Pull 主动拉取 + Exporter + 服务发现 + Pushgateway → PromQL 实例 + Alertmanager（分组/去重/静默/抑制）+ Thanos/VictoriaMetrics 长期存储 → Grafana 驾驶舱（不存监控数据、数据源、模板变量、ID 1860 一键导入）→ 可观测性三驾马车（Prometheus + Loki + Tempo）→ 全景总图。
