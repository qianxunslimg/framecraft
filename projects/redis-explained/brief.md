# 一集彻底搞懂 Redis · 创作简报

## 定位与目标
- **片长与规格**：约 5 分钟，1920×1080（16:9 横屏），30 fps，H.264 + AAC 48kHz 立体声。
- **完全独立成篇**：不依赖任何前后集，零基础观众看这一集即可从底层原理到生产实战彻底搞懂 Redis。
- **主演角色**：运维小牛马（`NiumaMascot`）+ 全新原创角色「Redis 闪电红立方精灵」（`RedisCubeBot`）。
- **配音与配乐**：`zh-CN-YunxiaNeural`（`+5%` 语速，`+0Hz` 原声，无儿化音，全部 25+ 专业英文术语逐词实听核验），搭配原创 130 BPM G 大调轻快内存电音 BGM 与 15 处定制音效。

## 7 幕知识蓝图（严格对标现代 Redis 6.x / 7.x）
1. **01 · 内存极速救场**：数据库磁盘 I/O 扛不住高并发 → Redis 亚毫秒内存缓存顶在前面，兼顾分布式锁/排行榜/限流/会话共享。
2. **02 · 五大核心数据结构**：String、Hash、List、Set、Sorted Set（ZSet）各自典型业务场景与直观图示。
3. **03 · 为什么这么快**：纯内存读写 + 核心命令执行单线程无锁竞争（准确点明 Redis 6.0 起引入多线程处理网络 I/O）+ epoll I/O 多路复用 + 高效底层数据结构（SDS/哈希表/跳表）。
4. **04 · 持久化双底牌**：RDB 快照（fork 恢复快、可能丢几分钟）vs AOF 追加日志（everysec 最多丢 1 秒、支持重写瘦身）+ Redis 4.0+ 混合持久化。
5. **05 · 缓存三大经典大坑**：缓存穿透（空值/布隆过滤器）、缓存击穿（互斥锁/逻辑过期）、缓存雪崩（随机过期抖动 + 高可用限流）。
6. **06 · 内存淘汰与高可用三件套**：TTL（惰性 + 定期删除）与 `maxmemory`（`allkeys-lru` / `allkeys-lfu`）+ 主从复制 → Sentinel 哨兵故障切换 → Redis Cluster 16384 哈希槽分片。
7. **07 · 一图收藏全景架构**：端到端知识蓝图 + 记忆口诀 + 小牛马与红立方精灵彩带谢幕。
