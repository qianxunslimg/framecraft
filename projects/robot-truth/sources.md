# 技术核验与素材来源（robot-truth）

## 具身智能与机器人工程核验清单
- **四大非全自主操控形态**：
  1. **手柄遥控与轨迹回放（Gamepad / Pre-programmed Keyframe Script）**：展会最常见形式，操作员通过手柄发送速度指令（`vx, vy, yaw`）或触发预录动作宏，属于开环回放或基础运动控制。
  2. **同构主从机械臂（Leader-Follower / ALOHA / GELLO）**：物理主从关节编码器 1:1 实时角度映射，低延迟且自带直觉空间感，广泛用于精细灵巧操作与模仿学习数采。
  3. **VR + 动捕手套 / 外骨骼逆运动学映射（VR Retargeting / IK）**：利用头显追踪手腕 6-DoF 位姿、数据手套捕捉手指关节，经实时逆运动学（IK）解算为异构机器人的关节角指令，并辅以第一视角双目图传。
  4. **半自主混合控制（Shared Autonomy / Wizard-of-Oz）**：底盘步态平衡由强化学习（RL Locomotion）自主完成、语音交互接入大模型，但在高风险抓取或任务决策瞬间由幕后操作员人工接管。
- **四大工程鉴伪维度**：
  1. **倍速剪辑与幸存者偏差（4×–8× Speedup & Cherry-picking）**：核对背景时钟、行人步速、水流与物体下落重力加速度，确认是否一镜到底（Uncut 1×）。
  2. **关节运动学微特征**：人类操作带有约 8–12Hz 生理微颤与约 150–250ms 视觉-运动闭环延迟；AI 模仿学习策略（如 ACT / Diffusion Policy）常呈现高度平滑样条或按固定 Action Chunking 周期出现的细微规划停顿。
  3. **随机对抗干扰测试（Closed-Loop Disturbance Recovery）**：开环回放脚本在目标被突发移位后会直接抓空；真正的视觉闭环策略会通过腕部/头部相机实时重定位并重新规划轨迹。
  4. **非结构化环境泛化**：对比纯白摄影棚单一道具 vs 杂乱桌面、透明器皿、多变光影与陌生形状物体的成功率。
- **遥操作的核心科研价值**：互联网缺乏大规模真实物理交互的「视觉-关节力矩-触觉」配对数据（Data Gap）；遥操作是采集高质量人类示范数据训练模仿学习（ACT / Diffusion Policy / VLA）的必经之路，行业争议点在于“把遥操作包装成全自主营销”，而非遥操作技术本身。
- **端到端自主 VLA 架构**：快慢双系统（System 2 VLM 2–5Hz 语义推理与空间锚定 + System 1 Diffusion/Flow Action Expert 50–200Hz 高频连续轨迹生成），结合 GPU 大规模并行物理仿真与域随机化（Sim2Real）提升泛化与抗干扰能力。

## 音频与视觉归属
- **配音**：Edge TTS `zh-CN-YunxiaNeural`（+12% 语速）本地分段合成并全篇实听核验。
- **配乐与音效**：本地 Python 程序原创合成（`scripts/bgm.py`），124 BPM C# 小调悬疑科技探索电子配乐 + X光扫描、示波器脉冲、告警与解锁音效。
- **视觉与仿真**：100% 由实时解析逆运动学（IK）机械骨骼引擎、物理仿真、双速播放器与 Canvas/SVG 代码实时渲染，零第三方版权素材。
